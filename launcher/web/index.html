    端口与运行模式

    下载与更新

    开启「共用一份素材」后，各版本目录里的 public/assets 与 public/fonts 会指向共享目录， N 个版本只需一份约 580 MB 的素材；改动此项后到「版本」页点「重建素材链接」生效。 不能建立链接的系统（部分 Windows）会自动改为复制。

    本地客户端素材（可选）

    从本机安装的《明日方舟》客户端里提取官方 3D 棋盘贴图、部分界面图标、灼热／炽焰源石虫模型和召唤物模型 （上游 tools/local-extract，见项目的 docs/DEPLOY.md 第 6 节）。没有它游戏照常运行， 只是 3D 棋盘退化成 2D、部分图标用替代样式。只在本机使用；提取需要 Python 3.8+（依赖约 40 MB， 装在安装目录内的 .venv-extract）。

    启动器更新

    开启后，启动器会在控制面板打开之前（此时没有任何对局在运行）检查自己的仓库并快进到最新版本，然后自动重启。 仓库无法访问、本地有未提交改动时会自动跳过，不影响使用；也可以在「主界面 → 启动器更新」里手动更新。

    添加版本（任意 fork）

    每个版本是一份独立、完整的源码检出（不叠加补丁），可分别启动。素材（约 580 MB）只下载一份， 各版本通过目录链接共用；删除版本不会删除共享素材。

    fork 的克隆会先走上面选择的「下载源」，失败时自动依次尝试其它公共镜像，所以直连 github.com 不通的网络也能安装 fork。

    从 Release 安装（不需要 git）

    这里装的是别人打好的版本包，自带依赖与前端库，装完不用 npm。 推荐选「源码包 / 精简包」：素材会走上面的共享区，只多下载约 25 MB； 「完整包」自带素材，但要多下几百 MB。增量更新包与语音包不能单独安装。

    收纳已下载的目录

    共享素材

    mod 源

    源是社区维护的工坊包仓库（），启动器只读取它的 mods/index.json 并按里面的 sha256 校验下载。本站不托管任何包。 工坊包在 Forge 版本上是原生安装；其它 ≥0.3.0 的版本会经引擎自带的转换器变成插件， 只有一部分包能转（改玩法/主题/接口端点那几类不行）。

    插件源（引擎的插件系统）

    这份目录随启动器一起用 git 管理（）， 只记录「有什么、适不适合当前引擎、要什么授权、去哪取」——启动器不托管任何包的字节。 有 release 包的条目直接装作者发布的 zip，并逐个用 sha256 校验；只有源码的条目由启动器从作者仓库取回文件夹， 再用引擎自己的 pack / check 打锁校验。也可以自己导入 zip 或填一个地址。

    插件没有全局启停：装进 plugins/ 只是就位， 实际由房主在房间里开（content/cosmetic）或玩家在设置里给自己开（ui）； script / trusted 两类默认不执行，需要服主设置 SP_PLUGIN_SCRIPTS 并在房间里逐人同意。装好后不用重启服务器，下次载入页面引擎就会认到。
